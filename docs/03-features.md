# 03 · 功能与用户流程

## 功能清单

### F1 · 无线连接 Pocket（主路径）

1. 用户点「无线连接」  
2. 若缺附近设备/蓝牙相关权限 → 权限门请求；可显示「授予附近设备权限」  
3. 若蓝牙关 → 请求开启蓝牙（失败则跳系统蓝牙设置）  
4. `WirelessSoftApTransport.connect`：加载 JNI、建 `PocketCameraSession`、开始扫描  
5. 若有 `lastCameraId` → 暖重连该 id；否则盲扫，发现第一台自动连  
6. 用户也可在列表点选其它相机  
7. 阶段推进：扫描 → GATT → 唤醒和配对请求 →（相机屏确认）→ 读 Wi‑Fi → 加热点 → 开 datalink → Live
8. Live 后自动导航进监视页（每个连接周期一次）

失败常见原因：未退 DJI Mimo、JNI 缺失、无蓝牙、权限拒绝、距离远。
「Pocket 状态」报告连接步骤，不把未发现设备当作关机；唤醒依赖相机仍可通过蓝牙响应。

### F2 · 有线网络摄像头（UVC）

用户点「有线连接」后按需申请 CAMERA 权限；连接前需在 Pocket 选择「网络摄像头」(2秒)，再以 USB/OTG 接入。Pocket 必须以标准 USB Video Class 设备被 Android Camera2 HAL 暴露为 `LENS_FACING_EXTERNAL`。应用只枚举外部 Camera2 摄像头，选取不超过 1920×1080 的 SurfaceTexture 输出尺寸，并直接将真实帧输出至 TextureView；只有会话配置且 TextureView 收到帧后才报告 Live/画面就绪。无线 GLES/解码链不变；有线不声明厂商 Bulk、不打开 MSC/RNDIS/AOA，也不控制机身模式。

Android 外接摄像头 HAL/provider 属 OEM 可选能力；若没有外部 cameraId，显示相应诊断并保持非 Live。相机权限拒绝也会说明原因。拔线关闭 Camera2 会话。机内录制由 Pocket 本身控制，不代表 App 支持录制控制。Mac 侧接口证据另见 `docs/09-wired-usb-evidence.md`。

### F3 · 实时监视

- Live 时根级 `LiveFeedHost` 出图  
- 顶栏无整条黑底（`chromeStatus` → `MonitorChrome`）：模式／规格／色彩与 EV／ISO／白平衡叠字显示，右侧「断开连接」。支持视频／拍照／动图／低光／慢动作／静止·轨迹·运动延时／全景等识别；延时与全景子参数见 `docs/10-mode-hud-capture.md`（只显示、不改机身）。**手机竖屏**芯片两排，录制时长贴在首行（D-Log 等）右侧空位；**手机横屏**录制时长在芯片与「断开」之间偏左；**平板**仍一行靠右。
- 顶栏下方仅在对焦相关状态时显示操作提示。
- LUT 选择器：内置约 80+ 款打包 LUT；加宽对话框；左侧可滚筛选（全部／收藏／标签／合集），右侧可滚条目；星标收藏；可导入自定义 `.cube`。仅预览，不改机身。
- 从相册返回监视会等相机退出回放再恢复 live；监视页会周期探测并恢复静置后变旧的画面。
- 顶栏「4K / 3K」是机身**录制**规格；旁注「直播 W×H」才是 SoftAP 实际出图尺寸（通常远低于录制，例如约 720／1080 级）。无线直播清晰度由机身预览流决定，应用不能单独拉到 4K；提高直播码率会明显增加 SoftAP／编码耗电与发热。
- SoftAP 晃动时若视频断流但状态 ACK 仍在，优先重发 live enable，避免过早拆 UDP 把短暂卡顿拉长成数秒黑屏。
- 无线拍照切到 `1:1` 时，Pocket 4P 实测会发送 `720×720` 的可见画面。监视器按实际码流尺寸等比完整显示，空余区域为纯黑；不把宽流拉伸或再做方形裁切。
- 底栏：首页 / 设置 / 相册；点「首页」只切换页面，保留会话。
- 手机横竖切换跟随传感器；相机码流翻拍只调整画面矩阵。
- 横屏默认隐藏 HUD 和系统栏，轻点显示控件；连接恢复失败时可手动重试。
- 直播时常亮 + 尽量最高刷新率  

### F2b · 诊断日志

- 启动即写入应用内日志（环形缓冲 + `files/logs/pocketglance-diag.log`），有线枚举／声明接口等会记详细条目；周期性镜像到 `Android/data/…/files/logs/`。
- 独立设置页：查看日志、清除日志、导出／分享、同步供电脑读取；说明里给出 `adb pull` 路径。平板首页右侧只保留常用显示／连接偏好，不含诊断日志。

### F4 · 断开与切模式

- 首页或监视右上的「断开连接」调用 `disconnect()` 结束会话，不发送停录命令。状态回到 Idle 后，监视器沿用现有路由返回首页，可重新连接。
- `GlanceModel.connect` 换模式会先断旧 Transport  

### F5 · 设置页 · 默认连接方式

独立 **设置** 路由（主页右上角 / 监视底栏可进）。  
三项：上次连接 / 无线连接 / 有线连接（`StartupPreference`）。  
偏好写入 DataStore；**冷启动自动按偏好发起连接尚未接线**（`resolveStartupMode` 已写好）。

### F6 · 相机相册

- 无线连接后，分别查询机身内存和存储卡，在平板上切换查看；不修改录制保存位置。
- 相册顶栏按系统相册组织：分段切换机身／存储卡、下划线切换全部／照片／视频，日期与标签为轻量筛选；布局用图标循环宫格／瀑布／大图。内容按拍摄日期分组并分页加载。
- 预览中左右滑动切换媒体，点画面切换底部缩略图条，点击缩略图跳转。点空白或向下拖动收起预览；返回监视入口只在相册浏览页。
- 长按或点「选择」进入单选、多选。删除需确认对话框；确认后向相机发送删除并立即从列表移除，不再要求手动核对。
- 顶栏刷新只重拉媒体目录，保持相机回放／相册模式，不会先退出到拍摄再重新进入。

### F7 · 上次相机暖重连

无线 Live 成功后记住 `last_camera_id`；下次无线 `startScan(reconnect=id)`，减少盲扫等待。

## 端到端：无线首次连接

```text
Home → 点无线 → 权限/蓝牙 OK
  → Connecting「正在扫描…」
  →（可选）发现列表 / 自动连第一台
  →「请在相机屏幕上确认配对」等
  → Live「无线已连接」
  → 自动 navigate Monitor
  → Surface 已 attach → 出图
```

## 端到端：翻拍

```text
Pocket 切换码流画幅，或云台姿态稳定横滚到左／右 90°
  → 监视器计算正向画面；原生竖拍不会再转 90°
  → 监视页请求正向竖屏；系统不旋转时，在现有窗口中直立显示
  → 画面、对焦点和追踪框共用变换，不重建解码 Surface
```

从监视器底部打开「设置 → 竖屏显示」：默认「锁定横屏」，竖画面完整居中、两侧为纯黑背景；「开放旋转」跟随 Pocket，竖画面请求正向竖屏，横画面请求横屏。如果平板系统屏蔽竖屏请求，应用将整个监视界面转成全屏竖向，不让系统用窄窗和壁纸填边。

点监视器左上角「横向／竖向」，可切回自动识别，或手动校正画面方向；不会修改录制画幅。部分云台模式会把镜头保持水平，仅转动手柄时可能没有可用于判断的镜头横滚。

## 非功能特性

- 中文 UI 文案（`GlanceCopy` + 硬编码中文）  
- 浅色品牌主题（米底 + pear/coral/azure）  
- 仅 arm64-v8a 包体  
- 明文流量允许（SoftAP）
